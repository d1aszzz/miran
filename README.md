# Miran — QR-меню и кабинет официанта

Два сайта:
- `index.html` — меню для клиента (сканируется по QR на столе)
- `waiter.html` — кабинет официанта (сканирует QR клиента / видит список активных заказов)

Оба сайта — обычные статичные HTML-файлы, их можно бесплатно разместить на GitHub Pages.
Данные о заказах хранятся в бесплатной базе **Firebase Firestore**, поэтому заказы видны
на любом устройстве в реальном времени.

## 1. Создать бесплатную базу данных (Firebase)

1. Откройте https://console.firebase.google.com и нажмите **Add project** (можно без Google Analytics).
2. В левом меню откройте **Build → Firestore Database → Create database**.
   Выберите режим **production** и ближайший регион.
3. Перейдите на вкладку **Rules** и вставьте:

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /orders/{orderId} {
         allow read, write: if true;
       }
     }
   }
   ```

   Это открытые правила — без пароля любой, кто знает адрес сайта, может читать и создавать
   заказы. Для MVP/одного зала этого достаточно. Если захотите ограничить запись только
   с ваших сайтов или добавить вход для официантов — на этом этапе можно подключить Firebase
   Authentication и ужесточить правила, скажите — помогу donастроить.

4. В настройках проекта (⚙ → **Project settings** → вкладка **General** → **Your apps**)
   нажмите **Add app → Web** (иконка `</>`), дайте имя (например, `miran-site`).
5. Скопируйте объект `firebaseConfig`, который вам покажут, и вставьте значения
   в файл **`firebase-config.js`** этого проекта вместо плейсхолдеров.

## 2. Выложить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `miran-menu`).
2. Загрузите в него все файлы этой папки (`index.html`, `waiter.html`, `firebase-config.js`).
3. В репозитории откройте **Settings → Pages**, в разделе **Source** выберите
   ветку `main` и папку `/root`, сохраните.
4. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://ваш-логин.github.io/miran-menu/`

## 3. QR-коды на столы

Для каждого стола сделайте QR-код, ведущий на:

```
https://ваш-логин.github.io/miran-menu/?table=НОМЕР_СТОЛА
```

Номер стола автоматически подставится в поле заказа. Сгенерировать QR можно
на любом бесплатном сервисе (например, qr-code-generator.com) или я могу
сделать вам PDF-лист с QR-кодами на все столы — просто скажите, сколько столов.

## 4. Официант

Ссылку на `waiter.html` дайте официантам (можно добавить на домашний экран телефона —
будет открываться как приложение). После оформления заказа клиентом на его экране
появляется QR — официант сканирует его вкладкой «Сканировать» либо просто открывает
вкладку «Активные заказы» и видит все текущие заказы в реальном времени, без сканирования.

## Ограничения этой версии

- Нет входа/паролей у официантов — ссылку на `waiter.html` не стоит выкладывать публично.
- Заказы не удаляются автоматически — можно вручную чистить коллекцию `orders` в консоли
  Firebase раз в день/смену, либо попросить меня добавить автоочистку.
- Меню сейчас "зашито" в код (`index.html`). Если нужно редактировать цены без
  разработчика — можно вынести меню в отдельную коллекцию Firestore с админкой,
  тоже могу собрать.
